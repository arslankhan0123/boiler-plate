Six responsive patterns

Every strategy to keep tables usable on narrow screens — horizontal scroll, stacked cards, hidden columns, priority + expand, dual render and sticky first column. Pick the one that fits your data density.

6 patterns Pure CSS Mobile-first

1 · Horizontal scroll

Simplest strategy — wrap the table in .table-responsive. The whole table scrolls sideways when it overflows.

Choose the right pattern
  • Horizontal scroll — dense data grids where every column matters equally.
  • Stack — read-heavy lists where each row is a self-contained record.
  • Hide columns — when there's a clear priority order.
  • Expand — mixed priority where users occasionally need the details.
  • Dual render — highest visual polish; costs double the markup.
  • Sticky first column — comparison tables (users × metrics).
Accessibility
  • Stacked layouts still need a <thead> for screen readers (hidden visually with d-md-table-header-group).
  • Every expand toggle exposes aria-expanded and aria-controls.
  • Sticky columns should carry a subtle shadow so users notice they persist.
  • Do not remove information — moving it into an expand is fine, hiding it entirely is not.
