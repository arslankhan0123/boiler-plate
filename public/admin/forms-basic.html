Usage guidelines
  • Always pair every input with a visible <label> — never rely on placeholder alone.
  • Group related switches in a form-check block; avoid mixing switches and standard checkboxes in a row.
  • Prefer floating labels in compact spaces; use standard labels in dense forms.
  • For selects with 8+ options, switch to the searchable variant.
Accessibility notes
  • Every input has an id and a matching <label for>.
  • Icons in input groups are decorative — the label carries the meaning.
  • Custom controls expose role, aria-expanded and keyboard nav.
  • Focus outlines stay visible — never outline: none without a replacement.
