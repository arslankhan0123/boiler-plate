Best practices

  • Keep tab labels short — one to two words works best.
  • Use pills for secondary navigation, tabs for content switching.
  • Persist the active tab in URL hash for shareable links.

Accessibility

  • Bootstrap wires up role="tab", aria-selected and focus roving.
  • Ensure each tab pane has a unique id referenced by aria-labelledby.
  • Support arrow-key navigation between tabs (built in).
