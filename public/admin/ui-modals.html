UI Components

Modals

Overlay dialogs for forms, confirmations, wizards and rich media — including a multi-step wizard, typed-delete confirmation and image lightbox.

Explore variants Bootstrap docs
Basic Sizes Scrollable With form With tabs Wizard Danger confirm Static Gallery

Basic modal

Header, body and footer — the standard dialog.

<button data-bs-toggle="modal" data-bs-target="#m">Open</button>
<div class="modal fade" id="m">…</div>

Size variants

Small, default, large, extra-large and fullscreen.

<div class="modal-dialog modal-lg">…</div>
<div class="modal-dialog modal-fullscreen">…</div>

Scrollable & centered

Long content scrolls inside the modal body.

<div class="modal-dialog modal-dialog-scrollable modal-dialog-centered">…</div>

With form

Ideal for creating records without leaving the current page.

<form data-ui-form-toast="Contact saved">…</form>

Tabs inside modal

Segment a lot of settings across tabs without losing context.

<div class="modal-body"><ul class="nav nav-tabs">…</ul><div class="tab-content">…</div></div>

Wizard (3 steps)

Guided multi-step flow with previous/next controls.

<div data-ui-wizard>
  <div data-ui-wizard-step>Step 1</div>
  <button data-ui-wizard-prev></button><button data-ui-wizard-next></button>
</div>

Danger confirmation (typed)

User must type "DELETE" to enable the destructive action.

<input data-ui-confirm-typed="#btnConfirm">
<button id="btnConfirm" data-ui-confirm-action disabled>Delete</button>

Static backdrop

Prevents accidental dismissal — user must click Cancel or Close.

<div class="modal" data-bs-backdrop="static" data-bs-keyboard="false">…</div>

Image gallery lightbox

Click any thumbnail to open a fullscreen preview overlay.

<button data-ui-gallery-item="Sunset">…</button>
<div data-ui-lightbox class="ui-gallery-lightbox">…</div>

Best practices

  • Reserve modals for tasks that require full user focus.
  • Use static backdrop for irreversible actions.
  • Provide clear primary/secondary buttons — never rely on the X alone.

Accessibility

  • Bootstrap automatically traps focus and returns it to the trigger on close.
  • Set aria-labelledby to the modal title id.
  • Escape key should close (unless static — then use Cancel).
