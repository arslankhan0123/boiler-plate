Usage guidelines
  • Search first — global search filters across all visible columns.
  • Sort by clicking a header; click again to reverse; a third click clears it.
  • Filter per column with the funnel icon; text vs. select is auto-picked from the data.
  • Density saves your team screen real estate on big data.
  • Bulk actions only appear when at least one row is selected.
Accessibility notes
  • All controls are keyboard reachable; sort buttons announce state via aria-sort.
  • Row selection uses native checkboxes with an indeterminate master state.
  • Bulk-action region is aria-live="polite", so screen readers hear the selection count change.
  • Pagination uses <nav> semantics with a labelled current-page button.
  • Empty state and loading skeleton are both perceivable by assistive tech.
