Charts / Line

Line chart variants

Nine production-ready line chart patterns built on Chart.js v4 — from basic series to smoothed, stepped, dashed, annotated and time-series lines. Each variant reacts to Orchid's theme change event and rebuilds with a fresh palette.

Variants9
Data sourceChart.js v4
Theme-awareYes
InteractionsHover · Toggle
Basic Multi-series Smoothed Stepped Dashed Filled Labeled Annotations Time-series

Basic line chart

A single-series line with clean grid, muted ticks and Orchid's indigo accent. Perfect starting point for any trend visualization.

Snippet 
new Chart(canvas, {
  type: 'line',
  data: { labels, datasets: [{ label: 'Visitors', data, borderColor: '#4f46e5', tension: 0 }] },
  options: baseOptions(),
});

Multi-series line chart

Three overlaid series with a top-aligned legend, shared tooltip index mode and matching colored point markers.

Snippet 
datasets: [
  { label: 'Sessions',    data, borderColor: PALETTE.indigo  },
  { label: 'Signups',     data, borderColor: PALETTE.emerald },
  { label: 'Conversions', data, borderColor: PALETTE.amber   },
]

Smoothed / tension curves

Cubic bézier smoothing with tension: 0.5 softens sharp peaks — great for aggregate KPIs where micro-changes are noise.

Snippet 
{ borderColor: PALETTE.violet, tension: 0.5, pointRadius: 0 }

Stepped line

Discrete step transitions — ideal for status changes, tier upgrades or infrastructure counts that hold constant between events.

Snippet 
{ stepped: true, borderColor: PALETTE.emerald, fill: true }

Dashed / dotted comparison

Combine solid actuals with dashed targets and dotted forecasts to convey certainty in a single glance.

Snippet 
{ label: 'Target', borderDash: [6, 4] }
{ label: 'Forecast', borderDash: [2, 3] }

Line with gradient fill

Feathered gradient underneath the line adds depth without the noise of a full area chart.

Snippet 
backgroundColor: OrchidCharts.gradientFill('#22d3ee', .35, 0),
fill: true

Data points with labels

A tiny custom plugin draws each value above its point — useful in exports or when tooltips can't be relied on.

Snippet 
plugins: [{
  id: 'valueLabels',
  afterDatasetsDraw(chart) { /* draw ds.data[i] above each point */ }
}]

Peak & trough annotations

Highlight the highest and lowest points via variable pointRadius arrays and a custom label plugin — no external annotation plugin required.

Snippet 
pointRadius: data.map((_, i) => (i === maxIdx || i === minIdx ? 6 : 0)),
plugins: [{ id: 'peakTroughLabels', afterDatasetsDraw() { /* labels */ } }]

Time-series (last 30 days)

Real date labels generated at runtime and capped to 8 ticks — the underlying data updates whenever you reload the page.

Snippet 
labels: daysAgoLabels(30),
scales: { x: { ticks: { maxTicksLimit: 8 } } }
