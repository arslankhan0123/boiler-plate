Charts / Donut

Doughnut chart variants

Eight doughnut patterns — center labels, semi-circle gauges, multi-ring, live cutout slider, rounded caps, radial gradients and side-by-side comparison.

Variants8
Data sourceChart.js v4
Theme-awareYes
InteractionsSlider · Hover
Basic Center label Semi-circle Multi-ring Cutout slider Rounded caps Gradient Comparison

Basic doughnut

Five slices with a bottom legend and a 65% cutout — the workhorse Orchid style.

Snippet 
{ type: 'doughnut', options: { cutout: '65%' } }

Doughnut with center label

Custom plugin (afterDraw) writes a large number + caption at the exact chart-area center.

Snippet 
plugins: [{ id: 'donutCenter', afterDraw(chart) { /* $86K */ } }]

Semi-circle (180° arc) gauge

Set circumference: 180 and rotation: 270 to render only the top half — a compact gauge.

Snippet 
circumference: 180, rotation: 270

Multi-ring doughnut

Three datasets on the same chart render as concentric rings. Match colors per family for readability.

Snippet 
datasets: [inner, middle, outer]

Doughnut with dynamic cutout

A range slider live-updates chart.options.cutout and calls chart.update().

55%
Snippet 
slider.addEventListener('input', () => { inst.options.cutout = v + '%'; inst.update(); })

Doughnut with rounded caps

Set borderRadius: 20 on the dataset for a fully-rounded segment cap.

Snippet 
datasets: [{ borderRadius: 20 }]

Doughnut with gradient stops

Radial gradient per slice via the canvas context. Great for celebratory dashboards.

Snippet 
backgroundColor: (ctx) => ctx.chart.ctx.createRadialGradient(...)

Comparison doughnut (side-by-side)

Two matched-scale doughnuts for period-over-period comparison. Share the same color mapping to preserve semantics.

Q1 2026

Q2 2026

Snippet 
<div class="charts-grid charts-grid--2">
  <canvas data-charts-chart="donut-compare-a"></canvas>
  <canvas data-charts-chart="donut-compare-b"></canvas>
</div>
