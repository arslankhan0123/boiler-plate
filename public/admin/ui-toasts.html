UI Components

Toasts

Ephemeral notifications for asynchronous events — with 6 positions, variants, action buttons, countdown progress and undo patterns.

Explore variants Bootstrap docs
Basic Sticky Positions Variants With actions Stack Progress Undo

Basic auto-hide

Default 4-second auto-dismiss in the top-right corner.

<button data-ui-toast="success" data-ui-message="Backup completed" data-ui-title="Success">Fire</button>

Sticky (no auto-hide)

Toast persists until manually dismissed.

Note: for a truly non-dismissing toast, call orchidToast(msg, variant, { autohide: false }) from your JS.

orchidToast('Message', 'warning', { autohide: false, title: 'Action required' })

Positioned (6 corners)

Fire toasts in any of the six standard positions.

<button data-ui-toast="primary" data-ui-position="top-start">Top-left</button>

Variants

Contextual colors matching Bootstrap variants.

<button data-ui-toast="success" data-ui-title="Success" data-ui-message="Paid">Fire</button>

With action button

Add an inline action inside the toast.

<button data-ui-toast="primary" data-ui-message="…" data-ui-action="Reply">Fire</button>

Stack (5 quickly)

Fires 5 toasts staggered by 250ms.

<button data-ui-stack>Fire 5</button>

With countdown progress

A progress bar shrinks to visualize the remaining time.

<button data-ui-toast="info" data-ui-progress="true">Fire</button>

Undo pattern

Toast with 5-second window to undo the action.

<button data-ui-undo>Delete</button>

Best practices

  • Reserve toasts for transient, non-blocking feedback.
  • Pair destructive actions with an Undo button.
  • Keep messages short — one sentence maximum.

Accessibility

  • Toasts include role="alert" and aria-live="assertive".
  • Auto-hide durations should be at least 4s so users can read them.
  • Never place critical action confirmations only in a disappearing toast.
