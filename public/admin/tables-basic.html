Usage guidelines
  • Striped for scannable data lists.
  • Bordered for reports and price sheets where every cell matters.
  • Compact for logs and audit trails — never for public-facing content.
  • Colored rows only when the color carries meaning; pair with icons/badges too.
  • Always wrap tables in .table-responsive to prevent overflow on small screens.
Accessibility notes
  • Use scope="col" and scope="row" so screen readers can associate headers with cells.
  • Add a <caption> for tables that stand alone — it acts as a heading.
  • Do not convey information with color alone; back it with text or an icon.
  • Ensure contrast ratios stay above 4.5:1 when using contextual row colors.
  • Expandable rows need an aria-expanded toggle plus an aria-controls target.
